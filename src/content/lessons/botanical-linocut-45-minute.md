## What changes from the original

The teacher prepares 3 × 3 inch blocks before class with the student's drawing already transferred from a homework sketch. That removes the drawing session entirely.

## Session 1

Carve. Pull a spoon proof in the last five minutes.

## Session 2

Finish carving for ten minutes, then print. Set up inking stations before students arrive so printing starts right away.
